# Atelier 🎨

> *You seem pretty sad for a girl who loves to paint.*

**Atelier** is a minimalist, interactive art gallery website created to showcase paintings in a curated digital exhibition.

The project focuses on creating the feeling of walking through a small art gallery rather than browsing a traditional image grid.

##  Features

* Interactive introductory screen
* Smooth scrolling gallery experience
* Curated, asymmetrical artwork layout
* Individual artwork displays
* Hanging artwork presentation
* Artwork titles and details
* Responsive design
* Subtle animations and transitions

##  Built With

##  About

##  About

**Atelier** is currently a complete demo website created for a friend who creates art and paintings.

The project is being developed as a way to experiment with building a real-world web project from the ground up, including project structure, frontend development, responsive design, animations, Git/GitHub workflow, and the overall process of developing a website for an actual use case.

For now, Atelier is **strictly a demonstration project** and is not intended to be used as a commercial art store.

In the future, the project may evolve into a proper **art portfolio or an online platform for showcasing and potentially selling artwork**.

##  Current Status

**Demo / Work in Progress**

The current version is a functional demonstration of the website concept. The gallery, artwork presentation, visual design, and interactions are being developed and refined over time.

The project may continue to evolve beyond the current demo depending on how the artist wants to use it in the future.
